Скачивание установщика

Перейдите на unrealunity.dev/download и выберите версию для вашей ОС.

Windows

Запустите UnrealUnitySetup.exe и следуйте инструкциям.

macOS

Откройте .dmg и перетащите в Applications.

Linux

sudo apt install unrealunity-engine
